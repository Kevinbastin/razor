# 45-second A6 pitch script

“AI agents can make payments with legitimate user-approved mandates. The new failure is not always stolen authority—it is a hijacked goal. An attacker can place hidden instructions in content an agent reads, then redirect an otherwise normal grocery session to gift cards or crypto.

Here, Layer 1 passes because the mandate is valid and the amount is in scope. Layer 2 passes because the agent behaves normally. Layer 3 compares the approved purpose with the actual cart, detects intent divergence, and records the injected content or suspicious source that preceded it. Layer 4 produces a deterministic evidence packet, pauses an active mandate where appropriate, and gives the merchant an auditable dispute trail. We protect delegated authority without treating normal automation as fraud.”
